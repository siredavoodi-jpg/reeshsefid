# باشگاه وکلای افرا | دورهمی با AI

سایت استاتیک آموزشی و خدمات هوش مصنوعی حقوقی.

## ساختار

```
/
├── index.html                 ← صفحه اصلی
├── courses/
│   ├── index.html             ← کاتالوگ دوره‌ها
│   └── ai-for-lawyers/
│       └── index.html         ← دوره «هوش مصنوعی برای وکلا»
├── services/
│   └── index.html             ← صفحه خدمات
└── assets/
    ├── logo.jpg
    └── style.css
```

## انتشار روی GitHub Pages

1. یک ریپازیتوری جدید بسازید (مثلاً `afra-lawyers`).
2. محتویات همین پوشه را آپلود/پوش کنید.
3. در Settings → Pages، منبع را روی branch اصلی و پوشه `/ (root)` بگذارید.
4. سایت در آدرس `https://USERNAME.github.io/REPO/` در دسترس خواهد بود.
